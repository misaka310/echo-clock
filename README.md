# Echo Show 11 Dashboard

Echo Show 11のSilkで表示する、**全面背景＋右側に大きな時計・日付・東京の天気** を表示するシンプルな時計サイトです。**Echo Showの通常ホームは広告やおすすめ表示が多いので、それを避けて、時計と天気だけを静かに表示するために作りました。**

- 画面は壁紙が主役。情報は右側にまとめます。初回のみ、画面下部に再生ボタン（画面維持用）を表示します。
- 時計は東京時間の24時間表示（その下に日付）、天気はOpen-Meteoによる現在の東京の情報を15分間隔で更新します。
- [Keep Silk Open](https://gitlab.com/DaGammla/keep-silk-open) （MIT）を同梱し、Silkで再生ボタンを押した後に無音音声を再生することで、アイドル時のホーム画面への復帰を抑制します。**完全な固定は保証できません**。

## Echo Showで使う

公開URL: **https://misaka310.github.io/echo-clock/**

1. Echo Show 11に「アレクサ、Silkを開いて」と伝える（声を出したくない場合は、設定 → アクセシビリティ → Tap to Alexa を有効にすると、画面のアイコンからSilkを開けます）。
2. Silkのアドレスバーに公開URLを入力する。背景を変えたいときは末尾に `?bg=2` のように付ける（後述）。
3. 画面下部の**再生ボタン**をタップする。無音再生と全画面表示が始まり、ボタンは消える。
4. そのまま置いておく。時計は毎秒、天気は15分ごとに自動更新される。

注意:
- Alexaに音楽再生などを頼むと無音再生の方が止まり、画面を維持する効果が切れます。このページは表示専用と割り切ってください。
- ページを更新したり開き直したりした場合は、もう一度再生ボタンをタップしてください。

### 背景の切り替え・変更

**URLパラメータで切り替え**: 配信URLの末尾に `?bg=` を付けると背景を選べます。既定はAI生成の風景（山の湖）です。

| 指定 | 背景 |
|---|---|
| （なし） | 山の湖 `assets/bg-1.jpg`（AI生成） |
| `?bg=1` （`?bg=mountain`） | 山の湖 |
| `?bg=2` （`?bg=ocean`） | 海の夕焼け |
| `?bg=3` （`?bg=forest`） | 森の木漏れ日 |
| `?bg=4` （`?bg=gradient`） | 青グラデーション |

Echo Showでは、開きたい背景のURLをそのまま入力（またはブックマーク）してください。

**画像自体を差し替える場合**: 画像はリポジトリで管理します。既定の画像は `assets/bg-1.jpg`（AI生成の風景）です。差し替える場合は同名ファイルを置き換えるか、別のファイル名で追加して `styles.css` の `url("./assets/bg-1.jpg")` を変更してpushしてください。画像を端末に直接アップロードする画面はありません。旧既定の `assets/wallpaper.svg` も残してあります。権利のある第三者のイラストは公開リポジトリに同梱しないでください。

背景は縦横比の異なる画像でも `cover` で自動拡大されます（周囲は切り取られる場合があります）。情報パネルは画面右側に配置されるため、右側が煩くない画像が向いています。プライベートな写真や権利的に問題のある画像は公開サイトへ置く前によく確認してください。

### 手軽な表示確認

静的サイトです。 `python -m http.server 8000` をリポジトリ直下で実行し、PCのブラウザから `http://localhost:8000` を開きます。無音再生OSSはSilkのUser Agentでのみ実行します。

## 公開について

このリポジトリは公開リポジトリで、GitHub Pages（mainブランチ / ルート）で配信しています。**公開URLは、URLを知っている人なら誰でも開けます。** 個人が写った写真など、見られて困る画像は背景に使わないでください。

**Alexaアプリだけでは標準ホーム画面をこのサイトに置き換えられません。** ブラウザを開いた状態で利用します。

```sh
python -m unittest discover -s tests -v
```

自動テストは構造・リソース・表示ルールを検証するもので、Echo Show 11実機の連続表示を保証しません。詳しくは `docs/SPEC.md` を参照してください。
