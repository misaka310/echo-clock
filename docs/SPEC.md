# Echo Show 11 dashboard — specification

## 1. 元の目的
Echo Show 11でAmazonのレシピ・おすすめ画面へ戻りにくくするため、Silkブラウザで使う専用の時計付き背景サイトを作る。ユーザーが選ぶ壁紙画像が主役で、画像の余白部分に東京時刻・日付・東京の天気・気温を表示する。

## 2. 期待する最終結果
- 表示エリア全体を背景画像で覆い、画像右側の余白に大きな24時間時計、その下に日付と「東京」「天気アイコン」「天気名」「℃」を縦に並べて表示する。情報はキャラクターの絵に重ねない。
- 東京時刻は Asia/Tokyo で更新され、外部の天気サービス Open-Meteo の現在値を15分間隔で更新する。
- 画像は `assets/bg-1.jpg`（AI生成の風景）を既定とし、任意の背景画像へ置き換え可能にする（Gitに追加して差し替える）。権利のある第三者イラストは同梱しない。加えて、URLパラメータ `?bg=` で同梱背景へ切り替えできる: `1`=山の湖 `assets/bg-1.jpg` / `2`=海の夕焼け `assets/bg-2.jpg` / `3`=森の木漏れ日 `assets/bg-3.jpg` / `4`=青グラデーション `assets/bg-4.jpg`（英語名 `mountain`/`ocean`/`forest`/`gradient` でも指定可）。パラメータなし・不正値は既定画像を使う。
- 元OSS Keep Silk Open をMITライセンスに従い利用し、Amazon Silkで最初の画面タップ後、無音音声によりブラウザのタイムアウトを抑制する。
- ローカルのWeb表示、ソースとテスト、README、公開GitHubリモート（GitHub Pagesで配信）を用意する。

### 完成扱いにしないもの
- コードとテストだけで、Echo Show 11実機で広告・レシピ画面への遷移が起きないと証明したとみなさない。
- GitHubのプライベートリポジトリだけでは Echo Show のSilkからサイトを閲覧できない。別途閲覧可能なHTTPS公開先が必要。
- AlexaアプリからEcho Showの標準ホーム画面を自作サイトへ置き換えたとみなさない。

## 3. ユーザー操作・導線

### Happy Path
1. 公開HTTPS URLを Echo Show 11 の Silk で開く。
2. 時計・日付・東京の天気・気温と背景が全面表示になり、情報が背景イラスト右側の余白に収まるのを確認する。
3. 画面下部の再生ボタン（初回のみ表示）をタップし、Keep Silk Open の音声再生を有効化する。同じ初回タップでブラウザへ全画面表示も要求する（Silk が拒否した場合は通常表示のまま使う）。
4. 20〜30分放置してホーム画面への自動遷移が起こらないか確認する。
5. 壁紙を変更するときは `assets/bg-1.jpg` を任意画像に差し替えるか、`styles.css` の背景参照先を変更して再配信する。

### エラー時
- 天気APIエラー時は以前の取得値（最新値を保持）か「--°」にし、時刻は維持。データが古いときは天気領域に取得失敗のツールチップをつける。
- 自動再生できない場合は初回のタップ案内を出す。Silk上のタップでも音声が始まらない場合はユーザーがブラウザを再読み込みする。
- GitHub非公開リポジトリは直接Web公開に使えない場合があるため、Cloudflare PagesのGit接続などHTTPSホスティングを別途設定する。

## 4. 制約条件
- Echo Show 11、Amazon Silk、常時表示を狙うブラウザ表示向け。画面は広告ブロッカーでなく通常のホーム画面を覆うWebページ。
- 情報は背景イラストの余白（既定画像では右側）に縦配置し、時計を最も大きくする。背景を覆う広い半透明パネルは使わず、白文字と濃い影で可読性を確保し、キャラクターの顔に情報を重ねない。
- OSSのライセンス文とソースを保存する。悪意のある画面操作やOS改変・ADBは使用しない。
- サイトをネットワーク接続できるHTTPSで配信する必要がある。サイトのURLが公開されていてもGitHubリポジトリ非公開は維持できる。
- APIキーを必要としないOpen-Meteoを利用する。天気は観測・モデルデータで保証されない。

## 5. 非目標
- Echo Show 11 のAmazon標準ホーム画面の交換、Alexaアプリ単体での自作サイト登録。
- 画面が絶対にホームへ戻らないことの保証、Alexa音声操作を使った再帰的な復帰。
- リモートからの壁紙編集アプリやパスワード付きサイト管理画面。

## 6. 受入条件
- [ ] 初期画面が背景全面と右側余白の時計・日付・天気になり、時刻の東京時間表示と天気・気温の正しい読み取りができる。
- [ ] OSS統合が動作し、手動タップから無音プレーヤーが開始できる。
- [ ] 背景を変更でき、天気API失敗時に時刻表示が途切れない。
- [ ] 自動テストとブラウザ表示を検証した。
- [ ] GitHub非公開リモートに最新コミットをpushして可視性を確認した。
- [ ] 配信されたHTTPS URLでEcho Show 11実機の長時間画面固定を確認した（手元の実機操作が必要）。

## 7. 検証方法
- `python -m unittest discover -s tests -v` でHTML/JS構成・ライセンス・表示と失敗時のコード経路を静的検証。
- PCブラウザでレイアウト、時刻、API表示とタップ案内を視認。
- Echo Show 11では一度タップし、20〜30分放置して自動帰還と天気の挙動を観察。
- `git status` / `git ls-remote` / GitHub APIで最新参照とprivate可視性を確認。
